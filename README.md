# 🎮 遊戲復盤網站

從 Google Drive 自動讀取遊戲復盤影片,依日期整理後顯示在 GitHub Pages 上。訪客不需要登入 Google 帳號即可觀看。

---

## 一、第一次設定

### 1. 建立 Google Drive 資料夾

1. 在 Google Drive 建立一個資料夾,命名為 **遊戲復盤**。
2. 底下可以依日期建立子資料夾,命名格式建議是 `YYYY-MM-DD`,例如:
   ```
   遊戲復盤/
   ├── 2026-09-27/
   ├── 2026-09-26/
   └── 2026-09-25/
   ```
   **如果資料夾沒有照這個格式命名也沒關係**:網站會自動改用「影片本身上傳到 Google Drive 的時間」來決定要歸類到哪一天。也就是說,子資料夾要不要照日期命名完全隨意,規則是:
   - 資料夾名稱是 `YYYY-MM-DD` → 用資料夾的日期
   - 資料夾名稱不是這個格式 → 用該支影片自己的上傳日期
3. 右鍵點「遊戲復盤」資料夾 →「共用」→「一般存取權」改成 **知道連結的任何人**,角色選 **檢視者**。
4. 上傳幾支影片到日期資料夾後,建議點開個別影片檔案確認也是「知道連結的任何人可檢視」(有時新上傳的檔案不會自動繼承資料夾權限,保險起見手動確認一次)。
5. 開啟「遊戲復盤」資料夾,從網址列複製 **Folder ID**:
   ```
   https://drive.google.com/drive/folders/【這一長串就是 Folder ID】
   ```

### 2. 建立 Google Cloud API 金鑰

1. 前往 [Google Cloud Console](https://console.cloud.google.com/)。
2. 建立一個新專案(或使用現有專案)。
3. 左側選單「API 和服務」→「程式庫」,搜尋 **Google Drive API**,點擊「啟用」。
4. 「API 和服務」→「憑證」→「建立憑證」→「API 金鑰」。系統會產生一組金鑰字串,先複製起來。
5. **重要:限制這組金鑰**,點進剛建立的金鑰進行編輯:
   - **應用程式限制**:選「HTTP 參照網址」,新增一筆 `https://<你的GitHub帳號>.github.io/*`
   - **API 限制**:選「限制金鑰」,只勾選 **Google Drive API**

   這樣就算金鑰外流,也只能從你的網站讀取公開資料,無法用在其他地方,也無法修改或刪除任何檔案。

### 3. 把網站部署到 GitHub Pages

1. 開一個新的 **public** repository(建議直接叫 `game-review` 之類的名字)。
2. 把 `index.html`、`style.css`、`script.js`、`config.js` 四個檔案上傳到 repo 根目錄。
3. 打開 `config.js`,填入剛剛拿到的兩個值:
   ```js
   const API_KEY = "貼上你的 API 金鑰";
   const ROOT_FOLDER_ID = "貼上遊戲復盤資料夾的 Folder ID";
   ```
4. Repo 頁面 →「Settings」→「Pages」→ Source 選擇 `main` 分支 / root 目錄 → 儲存。
5. 等 1–2 分鐘,網站就會出現在:
   ```
   https://<你的GitHub帳號>.github.io/<repo名稱>/
   ```

設定只需要做這一次,之後不用再碰。

## 二、日常使用方式

以後每次錄完遊戲,只要:

```
錄遊戲 → 得到 MP4 → 丟進 Google Drive 對應日期資料夾 → 完成
```

不需要改任何程式碼,也不需要重新部署。打開網站(或重新整理)就會自動抓到新影片。

如果是**當天新的一天**,記得先在「遊戲復盤」底下建一個新的 `YYYY-MM-DD` 資料夾。

---

## 三、影片分組與排序規則

- **決定影片歸類到哪一天**:
  - 該影片所在的資料夾如果命名為 `YYYY-MM-DD` → 用資料夾的日期。
  - 資料夾名稱不是這個格式(隨便取名也可以)→ 改用這支影片自己上傳到 Google Drive 的日期。
- **日期分組的排序**:由新到舊排列。
- **同一天內的影片排序**:
  - 如果檔名開頭是 `2026/09/27/14:30` 這種格式,會優先用這個時間排序。
  - 否則,依影片上傳到 Google Drive 的時間排序。

## 四、搜尋功能

網站上方的搜尋框可以直接輸入片名關鍵字,即時篩選所有日期下符合的影片。

---

## 五、播放方式說明

影片是用 Google Drive 官方的內嵌預覽播放器顯示(點擊「▶ 播放」才會載入),影片本身完全由 Google Drive 提供,不會經過 GitHub 或任何第三方伺服器,也不會被下載或複製。

---

## 六、常見問題

**網站顯示「找不到任何資料夾」**
→ 檢查 `config.js` 的 `ROOT_FOLDER_ID` 是否正確,以及「遊戲復盤」資料夾的共用權限是否為「知道連結的任何人」。

**網站顯示「讀取失敗」**
→ 通常是 API 金鑰的「應用程式限制」網域填錯,或是 Google Drive API 沒有啟用。到 Cloud Console 確認這兩項設定。

**影片點了播放但是黑畫面**
→ 該支影片本身的分享權限可能還沒開,回 Google Drive 手動打開該檔案的共用設定。

**資料夾沒照 `YYYY-MM-DD` 命名,影片會不會被歸到今天?**
→ 不會歸到「今天」,而是歸到該支影片實際上傳到 Google Drive 的那一天,所以資料夾要不要照日期命名都可以正常運作。

## 七、檔案結構

```
repo/
├── index.html   ← 網站主頁面
├── style.css    ← 樣式
├── script.js    ← 讀取 Google Drive、排序、搜尋、播放邏輯
├── config.js    ← 存放 API 金鑰與 Folder ID(唯一需要手動修改的地方)
└── README.md    ← 這份說明文件
```
